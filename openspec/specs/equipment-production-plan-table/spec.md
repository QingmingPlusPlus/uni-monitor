# 设备生产计划实绩表规范

## 目的

在设备维度以单表呈现当前设备的小时别生产计划与实绩，保留现场 Excel 的核心字段和状态色，同时避免进入页面时被历史及未来计划淹没。

## 需求

### Requirement: 默认只展开进行中计划

设备生产计划实绩表 MUST 始终展示进行中计划，初次进入设备维度时 MUST 收起已完成和未开始计划。已完成和未开始状态 MUST 展示计划数量，并允许用户分别展开或收起；两个状态的展开状态互不影响。

#### Scenario: 初次进入设备维度

- **WHEN** 用户进入任一设备详情页
- **THEN** 表格只显示状态为 `active` 的计划明细
- **AND** 页面仍显示已完成和未开始计划的数量及展开入口

#### Scenario: 展开历史和未来计划

- **WHEN** 用户点击已完成或未开始状态入口
- **THEN** 表格追加展示对应状态的全部计划明细
- **AND** 再次点击同一入口后收起该状态明细
- **AND** 进行中计划始终保持展示

### Requirement: 表格字段与计算口径

生产计划实绩表 MUST 展示状态、日期1、日期2、班次、时间、制番、能力、计划、实绩、合格、流动、不良合计、废弃合计、可动率、达成率、合格率、实力、胜负、停止内容和停止时间。停止时间 MUST 包含起、止、耗时三个子列。

比率 MUST 按以下口径计算并显示一位小数：

- 可动率 = 实绩 ÷ 能力
- 达成率 = 实绩 ÷ 计划
- 合格率 = 合格 ÷ 实绩
- 实力 = 计划 ÷ 能力

任一比率的必要输入缺失或分母无效时 MUST 显示 `-`。实绩不低于计划时胜负显示“胜”，否则显示“负”；未开始计划不计算胜负。

#### Scenario: 未开始计划没有实绩

- **WHEN** 一条未开始计划只有能力和计划数
- **THEN** 实绩、合格、流动、不良、废弃及依赖实绩的比率显示 `-`
- **AND** 实力仍按计划除以能力计算
- **AND** 胜负显示 `-`

### Requirement: 大屏完整展示与窄屏滚动

在 1920px 级别的大屏可用宽度下，生产计划实绩表 SHOULD 一次展示全部字段；可用宽度不足时 MUST 允许表格横向滚动，且不得挤压字段内容导致不可辨认。

### Requirement: mock 数据边界

在真实设备生产计划接口接入前，本表 MUST 使用由设备详情 mock 生成的确定性数据，不得触发生产计划或实绩接口请求；页面无需显示 mock 标识。
