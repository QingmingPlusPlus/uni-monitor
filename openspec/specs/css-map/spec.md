# 厂区地图设备卡片规范

## Purpose

定义 `css-map` 设备卡片在不同设备占位方向、尺寸和运行态内容下的稳定展示规则，确保 WebGL Sprite 与 CSS3D 回退渲染结果一致。

## Requirements

### Requirement: 设备外框保持原始占位

未配置 `polygon` 的设备卡片外框、选择描边和点击区域必须（MUST）覆盖 `devices.json` 中设备或换算后子设备的完整原始占位，不得因信息内容宽度变化而缩小。配置 `polygon` 时，外框、内容和点击区域必须（MUST）裁剪到多边形轮廓。

#### Scenario: 宽设备信息区小于设备占位

- **WHEN** 设备实际宽度大于当前信息所需宽度
- **THEN** 信息区靠设备左侧显示
- **AND** 右侧剩余区域保持白色留白
- **AND** 设备外框、选择描边和点击区域仍覆盖完整设备占位

### Requirement: 设备支持局部坐标多边形

设备和子设备可以（MAY）通过 `polygon` 顶点数组描述非矩形轮廓。顶点必须（MUST）以设备自身左上角为原点，位于 `0..width` 与 `0..height` 范围内，至少包含三个点并形成非零面积；未配置 `polygon` 时必须（MUST）保持现有矩形行为。子设备多边形必须（MUST）随子设备宽高从外层 100×100 局部坐标换算到地图坐标。

#### Scenario: 绘制多边形设备

- **WHEN** 设备配置包含有效 `polygon`
- **THEN** Sprite 渲染器沿顶点顺序绘制并裁剪设备卡片
- **AND** CSS3D 回退渲染器使用相同轮廓
- **AND** 点击多边形外接矩形内但轮廓外的透明区域不会打开设备

#### Scenario: 未配置多边形

- **WHEN** 设备配置不包含 `polygon`
- **THEN** 设备继续使用原有圆角矩形外框和矩形点击区域

### Requirement: 右侧 L 型设备支持专用内容排列

配置 `contentLayout: "right-l-shape"` 且具有有效右侧 L 型 `polygon` 的设备必须（MUST）从多边形提取横条高度和右侧竖条起点，并在顶部横条内排列原有内容。名称、状态、负荷率、人员和 5M 五类内容必须（MUST）全部保留；右侧凸出竖条必须（MUST）保持无状态色和负荷率色的白色留白；Sprite 与 CSS3D 回退渲染器必须（MUST）使用一致的区域划分。

#### Scenario: 显示右侧 L 型设备的全部内容

- **WHEN** 右侧 L 型设备配置 `contentLayout: "right-l-shape"`
- **THEN** 名称和状态显示在顶部横条
- **AND** 负荷率显示在横条下半区左侧
- **AND** 人员与 5M 在负荷率右侧分两行显示
- **AND** 右侧凸出竖条保持白色且不承载信息
- **AND** 所有信息均位于多边形有效区域内

#### Scenario: 专用布局与形状不匹配

- **WHEN** 设备声明 `contentLayout: "right-l-shape"` 但无法从 `polygon` 提取有效横条和竖条
- **THEN** 渲染器回退到按设备宽高规划的通用布局

### Requirement: 信息区按设备方向和内容分档

信息区必须（MUST）根据设备原始宽高选择布局方向，并根据名称、工况、负荷率、可见人员和可见 5M 标记估算所需宽度。`height >= width` 使用纵向布局，否则使用横向布局；布局方向和宽度档位不得因地图缩放而改变。

文本估宽必须（MUST）使用稳定字符权重：中日韩及全角字符为 `1em`，ASCII 字母数字为 `0.62em`，空格和标点为 `0.5em`。纵向宽度档位为信息区高度的 `0.55 / 0.70 / 0.85 / 1.00`，横向宽度档位为 `1.50 / 1.75 / 2.00 / 2.25`，并选择能承载当前内容的最小档位。

#### Scenario: 纵向细长设备

- **WHEN** 设备原始高度不小于宽度
- **THEN** 信息按名称、工况、人员、5M 变化点、负荷率的顺序纵向排列
- **AND** 信息区所需宽度不小于设备宽度时占满设备内部宽度
- **AND** 名称最多显示三行

#### Scenario: 横向宽设备

- **WHEN** 设备原始宽度大于高度
- **THEN** 信息使用上方名称与工况、下方负荷率与人员/5M 的横向紧凑结构
- **AND** 设备宽度超过所选内容档位时只在左侧档位宽度内绘制信息
- **AND** 名称最多显示两行

#### Scenario: 地图缩放

- **WHEN** 用户平移、缩放、聚焦或展开地图
- **THEN** 同一设备的方向和内容宽度档位保持不变
- **AND** 仅允许已有的名称完整/省略显示规则随缩放档位变化

### Requirement: 人员和 5M 标记语义保持不变

人员必须（MUST）继续使用现有班次扇形标记，5M 变化点必须（MUST）继续使用“人/机/料/法/环”方块标记。纵向布局最多使用三列两行共六个槽位，横向布局最多使用五个单行槽位；内容超过槽位容量时，最后一个槽位必须（MUST）显示 `+N` 汇总。

#### Scenario: 标记数量超过布局容量

- **WHEN** 人员或 5M 标记数量超过当前方向的槽位容量
- **THEN** 保留容量减一数量的原有标记
- **AND** 最后一个槽位显示未单独绘制的总数 `+N`

### Requirement: 默认和回退渲染器一致

WebGL Sprite 默认渲染器与 CSS3D DOM 回退渲染器必须（MUST）使用同一方向判断、内容宽度档位、标记容量和信息顺序。

#### Scenario: WebGL 初始化失败

- **WHEN** 页面从 Sprite 地图回退到 CSS3D 地图
- **THEN** 同一设备的方向、信息宽度和留白行为保持一致
- **AND** 不改变设备数据、路由或交互契约
