# 生产性推移表规范

## Purpose

定义部门维度和工序维度的生产性推移表装配方式、六行指标、聚合公式、周期截止、图表语义与真实接口边界，缺失的实绩 MH 不得伪造。

## Requirements

### Requirement: 部门和工序按所属工序展示卡片

系统 MUST 在部门维度和工序维度展示生产性推移表。部门维度 MUST 按 `departmentProcessMap` 的顺序为每个所属工序生成一张卡片；工序维度 MUST 只生成当前工序的一张卡片。生产性卡片 MUST 位于真实生产计划实绩推移表之后；真实生产计划实绩推移表 MUST 位于入库卡之后，入库卡隐藏时紧接出勤率推移表。

#### Scenario: 制造4课展示两张卡片

- **WHEN** 用户进入制造4课部门维度
- **THEN** 系统 MUST 依次展示“加硫2 生产性推移表”和“后处理2 生产性推移表”
- **AND** 两张卡片 MUST 分别使用加硫和后处理口径

#### Scenario: 工序维度只展示当前工序

- **WHEN** 用户进入任一工序维度
- **THEN** 系统 MUST 只生成一张生产性推移表
- **AND** 卡片标题和数据口径 MUST 对应该工序

### Requirement: 卡片固定展示六行指标

系统 MUST 按工序族展示两行数量、两行 MH 和两行个数生产性。前处理数量行 MUST 为“计划粘接数、实绩粘接数”，加硫 MUST 为“计划加硫数、实绩加硫数”，后处理 MUST 为“计划入库数（含待倒箱、端数等）、实绩入库数（含待倒箱、端数等）”。其余四行 MUST 为“计划MH、实绩MH、计划个数生产性、实绩个数生产性”。

#### Scenario: 后处理使用完整行名

- **WHEN** 系统生成后处理生产性卡片
- **THEN** 第一、二行 MUST 分别显示完整的计划和实绩入库数长行名
- **AND** 系统 MUST NOT 使用通用“生产数”替代该名称

### Requirement: 生产性指标使用真实生产接口

系统 MUST 使用 getPlan.number、getOutput.number 作为各工序的计划与实绩数量，使用 getPlan.mh 作为该条记录的计划 MH。后处理也 MUST 采用这两个接口的后处理数量，保持既有入库数行名。系统 MUST NOT 再使用固定数量、能力、提高基础数或模拟 MH；标题 MUST NOT 显示 mock 标识。

#### Scenario: 部门与工序范围保持一致

- **WHEN** 系统加载一张工序生产性卡片
- **THEN** 计划数量、计划 MH 和实绩数量 MUST 使用相同部门和工序范围
- **AND** 系统 MUST 沿用生产计划实绩卡片的设备范围筛选规则
- **AND** 无法归属当前范围的记录 MUST NOT 计入

### Requirement: MH 与个数生产性按周期合计派生

系统 MUST 按计划记录的 mh 直接求和，计划个数生产性 MUST 为计划数量合计除以未舍入的计划 MH 合计，MUST NOT 平均每日生产性。实绩 MH 计算方式尚未确定时，实绩 MH 与依赖该分母的实绩个数生产性 MUST 在所有周期显示 -，图表 MUST 使用 null，MUST NOT 以计划 MH 或其他未确认工时替代。

#### Scenario: 部分计划缺失 MH

- **WHEN** 某周期的任一计划记录 mh 缺失、null、负数或非有限值
- **THEN** 该周期计划 MH 与计划个数生产性 MUST 为空
- **AND** 系统 MUST NOT 使用剩余记录的 MH 作为全部数量的分母

#### Scenario: 真实零值与缺失区分

- **WHEN** 计划 MH 合计为真实零值
- **THEN** 计划 MH MUST 显示 0.0，计划个数生产性 MUST 显示 -
- **WHEN** 计划或实绩查询没有记录，或者发生 HTTP/业务失败
- **THEN** 对应指标 MUST 显示 -，MUST NOT 用零或 mock 补齐

### Requirement: 周期与班次截止沿用生产推移规则

紧凑态 MUST 展示当月、接口周分段和当前周工作日；展开态 MUST 展示当月、全部周和当前月全部日期。月和周计划 MUST 只累计至当前生产班次，当前生产日的日列计划数量与计划 MH MUST 展示当天全部班次。实绩数量 MUST 只累计至当前生产班次，未来日期 MUST 为空。00:00-06:29 MUST 归属前一生产日晚班。

#### Scenario: 当日计划与周累计使用不同截止范围

- **WHEN** 当前生产日仍有后续班次
- **THEN** 当日日列计划 MUST 包含当天全部班次
- **AND** 所在周与月计划累计 MUST 排除当前班次之后的计划

#### Scenario: 紧凑态不展示周末日列

- **WHEN** 当前周包含周六和周日
- **THEN** 紧凑态当前周日列 MUST 只展示工作日
- **AND** 展开态 MUST 仍可展示当前月全部日期

### Requirement: 表格格式保证指标可读

系统 MUST 将数量显示为带千分位的整数，将 MH 和个数生产性显示为一位小数。首列 MUST 提供足以完整显示后处理行名的宽度，当前约束为 `320px–340px`。

#### Scenario: 数量与小数采用不同精度

- **WHEN** 一个周期同时包含数量、MH 和生产性
- **THEN** 数量 MUST 以整数和千分位显示
- **AND** MH 与生产性 MUST 各保留一位小数

### Requirement: 图表使用柱线双轴且不展示 MH

图表 MUST 排除月列和两条 MH 系列。计划数、实绩数 MUST 使用分组柱状图并绑定左轴“千个”；计划个数生产性、实绩个数生产性 MUST 使用折线图并绑定右轴“个/MH”。表格 MUST 保留原始数量，只有图表数量 MUST 除以 `1000`。

#### Scenario: 图表固定四个系列

- **WHEN** 系统生成生产性图表
- **THEN** 图表 MUST 只包含两组数量柱和两条生产性折线
- **AND** 两条生产性折线的 `yAxisIndex` MUST 指向右轴
- **AND** 系统 MUST NOT 绘制计划 MH 或实绩 MH

### Requirement: 真实接口加载与刷新

系统 MUST 在同步加载和失败 fallback 中生成六行空表，MUST NOT 生成模拟数值。维度级 loader MUST 异步加载生产性卡片，多个工序 MUST 共享当月生产计划和实绩请求缓存。日期 MUST 限于当前月且通过有效性检查。

#### Scenario: 手动刷新生产性卡片

- **WHEN** 用户刷新生产性推移表
- **THEN** 系统 MUST 清除当前月 getPlan/getOutput 缓存并重新请求
- **AND** 系统 MUST 仅替换生产性卡片数组
- **AND** 系统 MUST NOT 调用尚未明确实绩 MH 算法的工时接口

### Requirement: 真实计划实绩与生产性卡片独立并存

部门和工序维度 MUST 各展示一张“生产计划实绩推移表”，通过 `getPlan`、`getOutput` 读取真实数量，按顺序展示计划生产数、实绩生产数、合格数、不良数、其他、达成率、合格率、不良率。部门 MUST 汇总所属工序，工序 MUST 仅统计当前工序。该卡片 MUST 与六行生产性卡片独立装配。

#### Scenario: 同时展示两类推移表

- **WHEN** 用户进入部门或工序看板
- **THEN** 系统 MUST 展示真实生产计划实绩卡片及所属工序的真实生产性卡片
- **AND** 两类卡片均 MUST NOT 显示 mock 标识

#### Scenario: 两种卡片独立刷新

- **WHEN** 用户刷新真实生产计划实绩卡片
- **THEN** 系统 MUST 清除当月计划和实绩缓存并重新请求两个接口，同时重取 getRejects
- **AND** 系统 MUST 保留当前生产性卡片
- **WHEN** 用户刷新生产性卡片
- **THEN** 系统 MUST 重新读取 getPlan/getOutput 并替换当前维度生产性卡片，MUST NOT 替换独立八行卡片

### Requirement: 质量缺口与图表系列

生产计划实绩推移表 MUST 将合格数、其他、合格率、不良率显示为 `-`，图表用 null，不以零或未经确认的差值补齐。原因 MUST 记录于接口缺口文档。不良数 MUST 读取 getRejects，仅聚合设备唯一归属当前范围、当前月且截止生产班次的有效非负数量，空数据和失败显示 `-`，真实零显示 0。刷新 MUST 重取不良接口，失败 MUST NOT 影响计划和实绩。

#### Scenario: 五项图例与空曲线

- **WHEN** 用户查看紧凑或展开图表
- **THEN** 图表 MUST 保留计划、实绩、合格数、达成率、合格率五个系列和图例
- **AND** 计划 MUST 为紫色虚线，实绩蓝色、合格数绿色、达成率浅蓝、合格率浅绿；比率 MUST 使用百分比右轴
- **AND** 合格数和合格率 MUST 使用空点，MUST NOT 绘制模拟曲线
