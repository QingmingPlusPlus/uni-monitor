## Purpose

定义部门和工序看板中人员出勤情况表的人员分类、直接在籍细分、合计计算与列展示规则，确保新人数量可独立核对且不会污染正式工和整体出勤指标。

## ADDED Requirements

### Requirement: 人员出勤表区分直接与间接人员
系统 MUST 使用实时出勤记录的 `positionType` 区分直接人员与间接人员，并 MUST 将职务名称包含“班长”的记录按间接班长口径展示，即使该记录的 `positionType` 为 `direct`。

#### Scenario: 普通直接人员参与直接口径
- **WHEN** 实时出勤记录的 `positionType` 为 `direct` 且职务名称不包含“班长”
- **THEN** 系统将该记录计入直接在籍合计和直接实际出勤人数

#### Scenario: 班长按间接口径展示
- **WHEN** 实时出勤记录的职务名称包含“班长”
- **THEN** 系统将该记录计入间接班长在籍和间接班长出勤，并且不计入直接在籍合计

### Requirement: 新人作为独立的直接在籍子类
系统 MUST 将 `positionType=direct`、职务名称不包含“班长”且 `positionName` 包含“新人”的记录计入新人列。系统 MUST 从正式工兜底数量中排除已计入新人列的人数，避免新人同时计入正式工。

#### Scenario: 新人记录显示在新人列
- **WHEN** 某班次收到一条 `positionType=direct` 且 `positionName` 包含“新人”的记录
- **THEN** 新人列增加该记录的 `schedulePersonCount`

#### Scenario: 新人不重复计入正式工
- **WHEN** 某班次存在已识别的新人记录
- **THEN** 正式工数量不包含这些新人，并且新人数量与正式工数量可以分别核对

#### Scenario: 没有新人记录
- **WHEN** 某班次没有符合新人条件的记录
- **THEN** 系统在该班次的新人列显示 `0`

### Requirement: 新人参与各层级合计但不改变整体出勤口径
系统 MUST 在班次明细、工序合计和部门全体合计中分别累加新人在籍人数。新增新人子类 MUST NOT 改变直接在籍合计、间接加直接在籍合计、直接实际出勤人数及出勤率的既有计算口径。

#### Scenario: 工序合计累加新人
- **WHEN** 同一工序的多个班次包含新人记录
- **THEN** 工序合计行的新人数量等于这些班次新人数量之和

#### Scenario: 部门全体合计累加新人
- **WHEN** 部门看板包含多个工序且这些工序存在新人记录
- **THEN** 部门全体对应班次及总计行的新人数量等于所含工序新人数量之和

#### Scenario: 新增分类前后整体指标一致
- **WHEN** 同一组接口记录在增加新人分类前后进行聚合
- **THEN** 直接在籍合计、直接实际出勤人数和出勤率保持一致，仅正式工与新人之间的细分数量发生变化

### Requirement: 人员出勤表展示新人列
系统 MUST 在人员出勤情况表的紧凑视图和展开视图中展示“新人”列，MUST 保留现有“顶岗”列，并 MUST 将“新人”放在“顶岗”之后、“合计”之前。直接分组表头和直接在籍子表头 MUST 完整覆盖新增后的列范围。

#### Scenario: 紧凑视图展示新人列
- **WHEN** 用户查看部门或工序看板中的人员出勤情况卡片
- **THEN** 表头按“顶岗、新人、合计”的顺序展示，并且每一数据行与表头列对齐

#### Scenario: 展开视图展示新人列
- **WHEN** 用户展开人员出勤情况卡片
- **THEN** 展开表使用与紧凑表相同的新人列顺序和数值

### Requirement: 直接岗位表头使用固定类别色
系统 MUST 在紧凑视图和展开视图中，仅为直接在籍岗位的末级表头使用高饱和度固定类别色：组长为绿色、正式工为蓝色、派遣工为橙色、临时工为黄色、新人为紫红色。系统 MUST 保持班长、顶岗、其他分组表头和数据单元格的原有颜色，并 MUST NOT 将岗位类别色应用到这些单元格。

#### Scenario: 紧凑视图显示岗位类别色
- **WHEN** 用户查看部门或工序看板中的人员出勤情况卡片
- **THEN** 组长、正式工、派遣工、临时工和新人末级表头分别显示高饱和度绿色、蓝色、橙色、黄色和紫红色，班长、顶岗与其他表头保持原有颜色

#### Scenario: 展开视图沿用岗位类别色
- **WHEN** 用户展开人员出勤情况卡片
- **THEN** 展开表使用与紧凑表相同的岗位末级表头配色，并且所有数据单元格仍使用原有颜色
